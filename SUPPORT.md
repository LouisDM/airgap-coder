# Support

Use [GitHub Discussions](https://github.com/LouisDM/airgap-coder/discussions) for setup questions, deployment patterns, and model compatibility reports when Discussions is available. Use the issue templates for reproducible bugs and feature requests.

Before asking for help, run:

```bash
./bin/lc doctor
./bin/lc test
```

Share command output only after removing private hostnames, addresses, usernames, tokens, request bodies, and model prompts. Never paste `.env` or generated configuration containing resolved credentials.

This community project has no guaranteed response time or service-level agreement.
