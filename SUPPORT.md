# Support

Use [GitHub Discussions](https://github.com/LouisDM/airgap-coder/discussions) for setup questions and deployment patterns. Use the [compatibility report](https://github.com/LouisDM/airgap-coder/issues/new?template=compatibility.yml) for exact backend results and the other issue templates for reproducible bugs and feature requests.

Before asking for help, run:

```bash
./bin/lc doctor
./bin/lc test
```

Share command output only after removing private hostnames, addresses, usernames, tokens, request bodies, and model prompts. Never paste `.env` or generated configuration containing resolved credentials.

Check the [troubleshooting guide](docs/troubleshooting.md) before opening a new topic.

This community project has no guaranteed response time or service-level agreement.
